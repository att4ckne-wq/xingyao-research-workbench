# 星钥科研智能工作台

面向“世界与AI / AI产品实现”的本地优先科研工作台。现有界面保留Workbench和Paper模块名称，本包基于正式已发布功能，仅在提交包内进行品牌更名；正式项目源码未变。团队个人署名由参赛者在报名系统填写。

## 评审者从哪里开始

评委可浏览公开仓库，或解压赛事材料中的源码快照。固定评审版本为 [7a5afdf](https://github.com/att4ckne-wq/xingyao-research-workbench/tree/7a5afdf54c7a39a3a258113d8c2db96e99d7687d)。

在 Windows x64 上按下文构建和启动。Windows 便携运行包正在内部验收，正式附件以 [Releases](https://github.com/att4ckne-wq/xingyao-research-workbench/releases) 为准。

## 核心能力

- 研究材料与正文锚点、人工来源确认和即时段尾引用编号。
- 用户确认发送上下文后使用自己配置的模型，保存独立工作稿。
- 内嵌Paper结构化记录，Workbench和Paper数据库独立。
- 本地数据制图和多格式成果生成；统计信息不足时明确显示草稿及导出提醒。

本地模板明确标注未调用模型。AI不能替代来源核对与科学判断，不宣称自动证实假设或进行真实实验。

## 源码复现

支持 Windows 10/11 x64。源码需要 Python 3.12、Node.js ≥22.13。OCR 另需 Tesseract 及 chi_sim、eng、osd 语言包。

在仓库目录中按各工具正式说明准备环境，然后执行：

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm ci
npm run build
```

上述步骤会安装依赖并生成本目录构建文件，请在独立源码目录执行，不指向已有科研数据。Python/Node版本和依赖锁文件以本仓库为准。

分别打开三个终端，运行：

```text
.venv\Scripts\python.exe -B 工具\启动源码服务.py api
.venv\Scripts\python.exe -B 工具\启动源码服务.py worker
.venv\Scripts\python.exe -B 工具\启动源码服务.py web
```

网页地址为http://127.0.0.1:3610/，API为8610。端口被占用时不自动结束其他程序；先关闭自己的旧实例或在工具参数中选择空闲端口。Ctrl+C停止各终端服务。该源码启动方式与便携版是两条独立路径，不要同时占用同一端口。
